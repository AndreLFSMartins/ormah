Task 1: The boot backfill stamps the real event time

File: 01-backfill-clock.md | Commit 1

Problem

_claim_confirmed_use stamps claimed_at = datetime('now') unconditionally, so the boot backfill records uses that happened 2–13 days ago as happening at startup. This pushes unearned recency into last_accessed (the decay anchor), last_review, and FSRS.

Format Facts

whisper_log.logged_at is Python isoformat ('2026-08-28T17:36:44.454369+00:00'); datetime('now') yields '2026-08-28 17:36:44'. SQLite's datetime() normalizes the former to the latter shape (offsets converted to UTC, malformed input → NULL). Mixed shapes would break the sweeper's lexicographic SQL (reinforcement_retry.py:52-54), so every stored claimed_at must stay space-format UTC.

Task 2: Load the node inside the write transaction

File: 02-load-in-transaction.md | Commit 2 | Depends on: Task 1

Problem

In _record_confirmed_use, node = self.file_store.load(node_id) runs BEFORE with self.db.transaction(). BEGIN IMMEDIATE can block up to busy_timeout=5000 ms (index/db.py:38) between the load and the save — a window this branch's diff widened (load and save were contiguous before it). Moving the load inside restores contiguity.

Scope note: This does NOT fix the pre-existing dual-writer race across processes — the commit message must say so.
