Vector Store Durability & Watermark Resilience

Stop the vector store from being silently wiped and stop the auto_linker watermark from freezing, so daily maintenance keeps running through restarts and config blips.

Goal & Scope

Three independent fail-closed hardenings, each its own commit + TDD:

  • Task 0: init_vec_table derives the stored dimension from the table DDL (works for empty tables) and refuses to DROP a populated store on a mismatch unless a dim-valued escape hatch authorizes it.
  • Task 1: The embedding backfill persists each chunk as it is encoded (durable + resumable in delta mode).
  • Task 2: auto_linker skips a vectorless node instead of aborting the whole run, with a WARNING when it parks the watermark.
  • Task 3: Full gate + deploy + operational recovery (unfreeze the cursor after the incident).

Root Cause & Context

Verified 2026-07-13, live Beta: Boot at 09:53 ran with embedding_dim=768 (`.env` mid-edit → config default), so init_vec_table DROPPED the 1024-dim store; boot at 10:28 (corrected `.env`, 1024) DROPPED again and re-created at 1024. Each drop left node_vectors empty, and auto_linker fail-closed-aborted on the first vectorless node → watermark frozen at 333726 with 12,135-node backlog. Non-resumable backfill (buffer-then-upsert) meant every restart mid-encode re-embedded all 12k from zero.

Council r1 (cursor ❌ / codex ⚠️) — Criticals & Highs

Critical (both peers)

The proposed raise sat inside init_vec_table's except Exception: pass → guard swallowed. The LIMIT 1 probe can't see an EMPTY mismatched table. Fix: derive dim from sqlite_master DDL, restructure so the guard is outside any broad except (Task 0 Steps).

High (codex)

A boolean escape hatch would re-authorize silent drops forever if left in .env. Fix: dim-valued flag — ORMAH_REINDEX_ON_DIM_CHANGE=<new dim> authorizes only a migration TO that exact dim; a later unrelated mismatch is still refused.

High (codex)

Parking the watermark can starve nodes beyond the auto_link_max_nodes_per_run window if a node is PERMANENTLY vectorless (poison). Decision: accepted residual risk — the incident class being fixed (mass-vectorless-during-catch-up) self-heals next run. Mitigation: WARNING log with the parked node id (Task 2). Dead-letter/retry set deferred (Task 3 Step 5).

Important (cursor)

stop_event contract — the interleaved design already flushes pending on cooperative cancel via the final _flush(). Comment clarified and a pinning test added (Task 1).

Medium (codex)

Chunked persistence makes DELTA mode resumable; SCHEMA mode still re-encodes all rows until the version advances (idempotent upserts — wasted compute, no data loss). Documented as the contract; schema-progress tracking deferred (Task 3 Step 5).
