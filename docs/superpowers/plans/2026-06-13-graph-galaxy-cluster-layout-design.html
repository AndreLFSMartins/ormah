Grouping by space is not decoration — it is the only thing that makes a 5.5k-node layout tractable.

PR #17 introduced an overview-first "galaxy" graph. After the maintainer's rework (ae1cdf4) dropped the fCoSE + hidden-hub pass for a single global cola run, the layout stopped converging on large graphs. This spec records the measured diagnosis and the chosen replacement: deterministic macro + local micro-force.

Why global force-directed fails

No global force-directed layout works for 5.5k clustered nodes:

  • cola runs incrementally (rAF, no freeze) but dissolves the space clusters — nodes with few intra-space edges have no force holding them in their space.
  • fcose would cluster (it is built for it) but its computation is synchronous and freezes the browser at this scale.
Key insight The hidden-hub pass that ae1cdf4 removed was what held clusters cohesive, not just a perf cost. Grouping by space partitions one 5.5k-node graph into ~70 sub-graphs of ~80 nodes — each a force layout resolves instantly. That partition is the lever. It also explains why mode OFF cannot get rich clusters.

The chosen shape — approach C

Replace the current pipeline (preset seed → global cola) with four deterministic steps plus isolated local force, when clusterBySpace ON (default):

1 Partition nodes by space — no-space nodes form the (no space) group
2 Micro-layout per cluster — headless cola, animate:false, avoidOverlap:true
3 Macro circle-packing — largest at center, pack outward until no collision
4 Compose positions + preset + fit — compact macro keeps it off the floor

Cross-space edges keep rendering (the existing subtle .cross-space class) and participate in no layout — they are visual only.

Mode OFF

Keep the current global cola, plus dynamic minZoom: after fit, if it clamped at the floor, lower minZoom so the whole graph fits — "always see the whole". There is no tractable partition without space grouping (the main connected component is likely thousands of nodes and reproduces the freeze from the diagnosis), so OFF is the crude-connections inspection mode by design.

Risk to validate

Headless cola Confirm cytoscape({ headless: true }) + cola animate:false yields usable positions, including node dimensions for avoidOverlap. If it does not work cleanly, fall back to a deterministic concentric micro-layout for the problematic clusters only — but try headless cola first, directly in the real-graph harness.

Verification targets

Reuse the existing playwright harness against the real graph:

  • fit zoom well off the floor (>> 0.03; PR head got 0.28 on a 3.5k graph)
  • separationRatio >> 1 (clusters separated; vs 0.12 today)
  • 0 overlapping node pairs (preserve the zoom-in-resolves-nodes property)
  • orphans ~0% outside their cluster
  • layout wall time < ~3s, no main-thread freeze

Out of scope

  • Reintroducing hidden hubs or a second fCoSE pass (the dropped approach).
  • Changing tier-based node colors, legend behavior, drag physics, or appearance settings.
  • OFF-mode clustering by an alternate dimension (tier/type) — considered and declined.
