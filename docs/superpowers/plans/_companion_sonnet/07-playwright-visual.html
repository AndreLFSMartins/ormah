Machine policy Run with: uv run --with playwright python ui/playwright/test_graph_layout.py. Never npm install playwright or Node Playwright imports.

Assertions

Layout ran All node positions are finite, and span_x > 0 and span_y > 0 — nodes are spread, not stacked at origin.
Cluster separation When there are ≥2 spaces with ≥2 nodes each, separationRatio ≥ 0.8 (centroid distance / mean intra-cluster spread). If fewer multi-node spaces, the separation check is skipped with an INFO log.
Canvas present Waits for a <canvas> element + 6000ms for FA2 to settle past its 4000ms window.
Screenshot Saved to /tmp/ormah_sigma_layout.png for manual inspection.

Step 2 — Write the visual test

Create ui/playwright/test_graph_layout.py. The test:

  1. Launches Chromium headless, navigates to http://localhost:8787
  2. Waits for <canvas> + 6000ms
  3. Reads window.__ormahGraph positions via page.evaluate()
  4. Checks finiteness and span
  5. If ≥2 multi-node spaces: checks separationRatio ≥ 0.8
  6. Saves screenshot to /tmp/ormah_sigma_layout.png
"""Visual layout test: after FA2 settles, nodes form organic clusters, not a grid.

Run the app first: make restart (serves built UI on :8787)
Then: uv run --with playwright python ui/playwright/test_graph_layout.py
"""
import math, sys
from playwright.sync_api import sync_playwright

URL = "http://localhost:8787"

def main() -> int:
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page(viewport={"width": 1440, "height": 900})
        page.goto(URL, wait_until="networkidle")
        page.wait_for_selector("canvas", timeout=30000)
        page.wait_for_timeout(6000)  # let FA2 settle past its 4000ms window
        data = page.evaluate("""() => {
          const g = window.__ormahGraph;
          if (!g) return { error: 'no graph handle' };
          const pos = {};
          g.forEachNode((id, a) => { pos[id] = { x: a.x, y: a.y, space: a.space || '' }; });
          return { pos, order: g.order };
        }""")
        page.screenshot(path="/tmp/ormah_sigma_layout.png")
        browser.close()

    # ... assertions (finite positions, span > 0, separationRatio >= 0.8)
    ...

if __name__ == "__main__":
    sys.exit(main())
