Task 5 · Force layout

FA2 web-worker wrapper

0 / 3 steps · todo

Thin wrapper around the graphology FA2 worker so GraphView never touches the worker API directly.

What this task does

Runs the simulation off the main thread, auto-stops after a configurable settle window (default 4000ms), and exposes re-heat for drag. Used by Task 6 and exercised end-to-end by Task 7.

Barnes-Hut optimization When graph.order > 1000, barnesHutOptimize is set to true automatically — keeping the simulation fast on large stores without manual tuning.

ForceLayout API

start()Starts the FA2 worker; arms the settle timer (4000ms by default). No-op if already running.
stop()Clears the settle timer and stops the worker.
kill()Clears the timer and terminates the worker thread. Called in React cleanup.
isRunning()Delegates to FA2Layout.isRunning().
reheat()Re-calls start() — restarts the simulation after a node drag. Called from Task 6.5.

No unit test — intentional

Known gap The worker uses a real Worker, which jsdom does not provide — so this module has no unit test. It is exercised by the Playwright visual test (Task 7). This is an intentional, logged gap, not a placeholder.

Step 1 — Write the implementation

Create ui/src/graph/forceLayout.ts:

import type Graph from "graphology";
import forceAtlas2 from "graphology-layout-forceatlas2";
import FA2Layout from "graphology-layout-forceatlas2/worker";

export interface ForceLayout {
  start(): void;
  stop(): void;
  kill(): void;
  isRunning(): boolean;
  reheat(): void;
}

export interface ForceLayoutOptions {
  settleMs?: number;  // default 4000
}

export function createForceLayout(graph: Graph, opts: ForceLayoutOptions = {}): ForceLayout {
  const settleMs = opts.settleMs ?? 4000;
  const inferred = forceAtlas2.inferSettings(graph);
  const layout = new FA2Layout(graph, {
    settings: {
      ...inferred,
      barnesHutOptimize: graph.order > 1000,
      adjustSizes: true,
      gravity: inferred.gravity ?? 1,
      slowDown: 1,
    },
  });

  let settleTimer: ReturnType<typeof setTimeout> | null = null;

  function clearTimer() {
    if (settleTimer !== null) { clearTimeout(settleTimer); settleTimer = null; }
  }

  function start() {
    if (layout.isRunning()) return;
    layout.start();
    clearTimer();
    settleTimer = setTimeout(() => layout.stop(), settleMs);
  }

  return {
    start,
    stop() { clearTimer(); layout.stop(); },
    kill() { clearTimer(); layout.kill(); },
    isRunning: () => layout.isRunning(),
    reheat() { start(); },
  };
}
