Task 3 · Graph model

Build payload → graphology graph

0 / 5 steps · todo

A pure function turning the /ui/graph payload into a graphology Graph with sigma-ready attributes.

What this task does

Seeds random initial positions (FA2 requires x/y before running). Filters edges whose endpoints are missing (matches current behavior, GraphView.tsx:545-546). Calls visual.ts for all attribute derivation — no color math here.

Seed positions Uses a deterministic ring seed (seedPosition()) so FA2 has distinct x/y to start from. FA2 rescales; exact seed positions don't matter, only that they exist and differ.

Test cases

Happy path
Single node with tier "core" and a title → correct label, color (from appearance.colors.core), positive size, finite x/y.
Missing space/tier
Node with space: null → attr.space stored as "" (no throw).
Empty payload
No nodes, no edges → graph with order=0, size=0.
Isolated node
Node with no edges → degree("lonely") === 0.
Edge filtering
Edge to a ghost node (not in nodes list) → dropped. Edge a→b → added with correct color from edgeColor("supports","dark").

import Graph from "graphology";
import type { GraphAppearance } from "../graphAppearance";
import type { GraphData } from "../types";
import { computeSelfRoles, displayNodeSize, edgeColor, nodeLabel, tierColor } from "./visual";

function seedPosition(index: number, total: number): { x: number; y: number } {
  const angle = total > 0 ? (2 * Math.PI * index) / total : 0;
  const r = 100 + (index % 7);
  return { x: r * Math.cos(angle), y: r * Math.sin(angle) };
}

export function buildGraph(data: GraphData, appearance: GraphAppearance): Graph {
  const graph = new Graph({ multi: true, type: "directed" });
  const roles = computeSelfRoles(data.nodes, data.edges, data.user_node_id);

  data.nodes.forEach((n, i) => {
    const role = roles.get(n.id) ?? "";
    const { x, y } = seedPosition(i, data.nodes.length);
    graph.addNode(n.id, { x, y, size: displayNodeSize(n.access_count, role),
      color: tierColor(n.tier, role, appearance), label: nodeLabel(n),
      space: n.space || "", tier: n.tier, selfRole: role });
  });

  for (const e of data.edges) {
    if (!graph.hasNode(e.source_id) || !graph.hasNode(e.target_id)) continue;
    graph.addEdge(e.source_id, e.target_id, {
      size: 1, color: edgeColor(e.edge_type, appearance.theme), edgeType: e.edge_type,
    });
  }
  return graph;
}
