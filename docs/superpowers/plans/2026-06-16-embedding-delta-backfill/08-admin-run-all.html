Sleep-cycle integration · needs Task 06

The change

Register the job in the admin task registry so the 02:00 sleep-cycle pass (POST /admin/tasks/run-all) runs it. embedding_backfill is a standard (module, function) runner, so it fits _TASK_RUNNERS directly (no index_updater-style special case).
