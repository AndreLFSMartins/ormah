Graph active-first com drill-down de espaço

Implementation Plan — issue #22, slice 1 (renderer sigma.js). Companion do plano dividido em docs/superpowers/plans/2026-06-27-graph-active-first/.
Goal: graph view carrega por padrão só o active graph (tiers core/working + nó self); archival sob demanda via drill-down de espaço.
Stack: backend Python/FastAPI/pytest (.venv/bin/python -m pytest); frontend Vite/TS/vitest (ui/).
Spec: docs/superpowers/specs/2026-06-27-graph-active-first-design.md · Vetado por 2 passadas do council.

00 · Overview

Gating no backend (GET /ui/graph): default retorna não-archival (+ nó self); ?space=S traz um espaço completo (active+archival); ?space= seleciona o grupo sem-espaço; edges podadas ao set de nós; campos aditivos all_spaces e has_no_space. O fetch e o viewScope vivem no App.tsx; o GraphView é apresentacional. Lógica testável isolada em funções puras (vitest só inclui src/**/*.test.ts; sem teste de componente).

Out of scope: coesão por espaço (fatia B), LOD (fatia C), on-demand por busca/foco, cap no active graph. Não regredir features do PR#17. docs/superpowers/ é gitignored.
