Introduction

Overview & Architecture

Stop the sleep-cycle credit bleed at its roots: schema-valid JSON from claude -p (so dedup merges parse) and a bounded + persisted + failure-safe dedup sweep (no thousands of LLM calls, no dead-LLM loop, no dropped merges).

Goal & Architecture

Reuse existing patterns:

  • (A) Response format seam: The response_format seam is already honored by the Ollama adapter; wire the claude_cli adapter to --json-schema + read structured_output (verified under subscription auth 2026-07-03).
  • (B) Dedup isolation: Dedup gets its own duplicate_checked table (NOT shared auto_link_checked), and persists only terminal outcomes: not_duplicate on a confirmed non-duplicate, error (with backoff) on a transient LLM failure — never duplicate (the merge's own invalidation + the pending-proposal check cover that side, so a failed/rejected merge is never permanently skipped).
  • Safety features: Per-run LLM cap and a consecutive-failure circuit breaker.
Council history

R2 (both rejeitou) → this revision: persist only not_duplicate/error never duplicate (drops-merge critical); error+backoff (breaker starvation); skip in _find_merge_candidates (agent-path re-churn); 5 invalidation statements incl. both merge DELETEs; real invalidation test; -1 cap sentinel (0-is-falsy footgun); reject-invalidation.
