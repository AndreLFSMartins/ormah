CasoO que fazerPor quê

4. Decisões abertas (a discutir / levar ao r-spade)

  • Recall normal continua vendo archival? Hoje vê (com −0,1). No modelo do r-spade, "normal recall searches active memory". Os dados não decidem — é mais dele que nosso.
  • Janela-alvo do working: stability inicial 7–14d coloca a demoção em ~10–20 dias sem sinal. Qual o número certo?
  • Injeção de whisper reforça stability? Recomendado sim, com peso menor que recall explícito — senão o FSRS nunca aprende. Risco: feedback-loop do que já está quente.
  • Importância: recalibrar o scorer (máx atual 0,56) ou baixar thresholds?
  • Sequência: calibração do relógio → UI WebGL upstream → cold layer + Deep Recall instrumentado → purge só com dados (3–6 meses de telemetria).
  • Bomba de outubro: com deleção armada e gates degenerados, a coorte do backfill (07-06→08) fica elegível em massa ~05/10. Calibrar antes disso ou desarmar.
